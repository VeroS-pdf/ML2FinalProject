# Barkesian Models

Collaborators: Alina Gonzalez, Veronica Song, Sophia Yang

# Project Overview

Pet ownership has long been associated with positive outcomes, from teaching children the responsibilities of caring for another life to combating stress and mental illnesses to working as service animals. But certain pets work better for people’s lifestyles, household dynamics, and personality traits. Our project aims to create an MLP predictive model that reads in a person’s personality traits and matches them to the type of pet that best fits them, a CNN classifier that identifies an adoptable animal’s species and key traits, and a Bayesian predictive model that predicts the likelihood of pet adoption based on the animal’s identified key traits.
